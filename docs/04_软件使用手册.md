# 04 软件使用手册

## 4.1 安装（Windows）

1. 安装 Python ≥ 3.9（推荐 3.11 或更高：Windows 上 `time.sleep` 精度更好）。Anaconda 环境也可以，例如您的 `torch24`。
2. 在工程根目录执行：
   ```bat
   python -m pip install -e .
   ```
   依赖：numpy、scipy、matplotlib、pyserial；Tkinter 随 Python 自带。
3. 验证：
   ```bat
   python -m pendulum_lab --version
   python -m pytest -q
   ```
   预期 62 项全部通过，约 30 s，其中 SIL 测试是实时运行的。

命令名：`pendulum-lab`（连字符，pip 安装的可执行文件）等价于 `python -m pendulum_lab`（下划线，Python 模块）。`pendulum_lab.exe` 不存在。

## 4.2 图形界面

```bat
python -m pendulum_lab gui
```

若 `config/physical_config.json` 存在，会自动加载（实物标定与辨识结果都存在这里）。

### 页 1 数字孪生仿真

- **控制算法**：LQR / 串级 PID / 极点配置 / 角度 PD / 能量起摆（仅仿真）/ 无控制。
- **控制器参数**：PD 与 PID 的 $\omega_n,\zeta$；LQR 的 $q$ 与 $r$；极点配置的极点（逗号分隔，如 `-7+5j, -7-5j, -3, -2`）；“考虑延迟 / 驱动器滞后”开关。
- **状态估计**：卡尔曼滤波或滤波微分；“估计角度零点偏差”。
- **数字孪生非理想因素**：初始角、$T_s$、执行与传感延迟、驱动器滞后、ADC 噪声、零点误差、皮带间隙、库仑摩擦、设计假设延迟；“孪生真实 ω0”与模型不同时即人为制造模型误差。
- **在线辨识 / 自整定**：off / monitor / update，“已知激励 ±3 cm 方波”。动画上方显示 $\hat\omega_0\pm\sigma$、真值、设计值、是否可信。
- **按钮**：应用并重置、运行/暂停、推杆（±0.6 rad/s 角速度冲击）、单步、导出 CSV；x_ref 滑块移动目标位置；播放速度 0.1–2 倍（慢动作讲解）。

### 页 2 闭环分析

显示所有线性控制器的增益、z 平面闭环极点、谱半径、延迟裕度。使用仿真页当前的 $T_s$、延迟和滞后。

### 页 3 参数辨识

- **① 角度标定助手**：依次记录下垂、直立、+x 侧倾，计算斜率与符号并保存。
- **② 自由摆动辨识**：先录 3 s 静止，响铃后把杆拉到约 90° 松手，默认录 60 s；也可载入 `record_potentiometer.py` 生成的 CSV。辨识 A1、A2、B 三种方法并画出振幅衰减与模型曲线。
- **③ 应用到模型**：写入 `plant`，所有控制器按新 $\omega_0$ 重新设计（确定性等价）。

### 页 4 驱动器（对应原厂上位机）

- **连接**：串口、波特率、协议（custom / modbus）、地址。连上后会读固件版本。
- **按钮**：使能、失能、立即停止（刹车）、清除电机状态、一键恢复（清除 + 使能）、清除当前位置、设为通信速度模式、打开指令回响、左右限位开/关、保存参数、**一键准备**、**就绪检查**。
- **点动**：按住运行、松开即停，最长 3 s。
- **系统参数**：电压、电流、转速、位置（计数与 cm）、使能、堵转、运行状态、工作模式；可自动刷新。
- **皮带标定向导**：①②③④四步，得到每圈行程、编码器方向、中心计数，并保存。
- **指令日志**：[发]/[收] 十六进制，格式与原厂一致，便于对照。

### 页 5 实物运行

- 选择传感器与驱动器串口、算法、时长、模式：影子（电机不动）/ 闭环 / 模拟实物（SIL，无需硬件）。
- 在线辨识：off / monitor / update；辨识激励开关。
- 红色“停止”按钮或**空格键**触发受控减速。
- 控制循环运行在**独立进程**中，GUI 绘图不会拖慢它（01 章 1.4.2 的实测对比）。
- 日志写入 `data/gui_<算法>_<模式>_<时间>.csv`。

## 4.3 命令行参考

| 命令 | 作用 | 会动电机？ |
|---|---|---|
| `params` | 几何估算、秒表拟合、当前模型参数 | 否 |
| `identify [--csv F] [--write cfg]` | 自由摆动辨识（无 CSV 时用秒表数据） | 否 |
| `design [--algos pd,pid,lqr,place] [--png]` | 增益、闭环极点、延迟裕度 | 否 |
| `simulate --algo lqr [--csv --png --kick t:v ...]` | 单算法仿真 | 否 |
| `compare [--algos ...] [--png] [--kick 5:0.5]` | 多算法同场景对比 | 否 |
| `gui` | 图形界面 | 视操作而定 |
| `diagnose --sensor COM12` / `--motor COM11 --protocol modbus` | 只读诊断：速率、噪声；版本、参数、就绪 | 否 |
| `probe --motor COM11 --rate-hz 100 --count 1000 --csv F` | 只读误码率与延迟 | 否 |
| `sensor-log --sensor COM12 --seconds 60 --csv F` | 记录原始 ADC | 否 |
| `calibrate-angle --sensor COM12 --write cfg` | 交互式角度标定 | 否 |
| `driver <action> --motor COM11` | info / prepare / enable / disable / brake / clear / recover / speed-mode / zero / limits-on / limits-off / save | enable 后可能 |
| `calibrate-cart --motor COM11 --write cfg` | 定义 +x、测每圈行程 | **是**（几厘米） |
| `motor-step --motor COM11 --config cfg` | 测延迟、速度环滞后、速度增益 | **是**（约 2 cm） |
| `run --mode shadow\|closed --algo lqr --config cfg [--adapt monitor]` | 实物实时控制 | closed 时**是** |
| `sil --algo lqr [--protocol modbus] [--true-omega0 5.0 --adapt update]` | 模拟实物跑完整硬件代码路径 | 否 |
| `report --log F` | 画图并统计日志 | 否 |

所有命令都支持 `--config`，JSON 会覆盖内置默认值。仿真类命令支持：`--Ts --latency --sensor-latency --tau --backlash --jitter --noise --offset-counts --coulomb --estimator --no-bias --design-latency --design-tau --x-source --seed --theta0 --duration`。

## 4.4 配置文件字段（`config/physical_config.json`）

| 路径 | 含义 | 默认 / 来源 |
|---|---|---|
| `plant.omega0, viscous_c, coulomb_gamma` | 摆杆模型 | 秒表拟合；辨识后更新 |
| `loop.Ts` | 控制周期 | 0.005 s |
| `loop.latency_estimate, actuator_tau` | 设计假设的总延迟与驱动器滞后 | 0.020 / 0.015 s，按 `motor-step` 更新 |
| `actuator.a_max, v_max` | 加速度与速度限幅 | 6 m/s² / 0.5 m/s（首次闭环建议 4 / 0.4） |
| `safety.*` | 倒杆角、软限位、刹车减速度、超时等 | 25°、±20 cm、3 m/s² … |
| `estimator.*` | 卡尔曼噪声参数、零偏开关与初值 | 见 `config.py` |
| `controllers.*` | 各算法设计参数 | 见 03 章 |
| `hardware.sensor_port / motor_port / *_baud / motor_address` | 串口 | COM12 / COM11 / 115200 / 1 |
| `hardware.motor_protocol` | custom 或 modbus | custom |
| `hardware.motor_accel` | F1 加减速字节 | 0（直接跟随） |
| `hardware.calibration.adc_upright, counts_per_rad, sign` | 角度标定 | 05 章第 2 步 |
| `hardware.cart.meters_per_rev, center_counts, sign` | 皮带标定 | 05 章第 4 步 |
| `hardware.motor_feedback_every` | 每几个周期读一次位置 | 2 |

## 4.5 日志列（实物运行）

`t` 时间、`dt` 实际周期、`state` 状态机、`seq` 传感器样本序号、`adc`、`sensor_age` 样本年龄、`theta_meas`、`x_meas`、`x_hat v_hat theta_hat omega_hat bias_hat` 估计、`a_ctrl` 控制器输出、`a_eff` 有效加速度、`v_cmd`、`motor_err` 连续通信错误、`tripped` 安全触发、`omega0_hat` 在线辨识。

## 4.6 代码结构与扩展

见 README。新增控制算法的步骤：

1. 在 `control/controllers.py` 继承 `Controller` 实现 `update()`；若是线性律，再实现 `law()`，就能自动得到闭环分析；
2. 在 `config.py` 的 `make_controller` 中注册；
3. GUI 和 CLI 会自动可用，仿真与实物使用同一份代码。
